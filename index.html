Pele, styled without touching core.

Add a white theme, drop shadows, entrance animations, and Lucide icons using Pele’s existing CSS hooks and icons option. No fork, plugin, build step, or modified Pele bundle.

Stock Pele 1.12.0 One HTML file CSS + vanilla JavaScript

Start with stock Pele

Load Pele’s browser build and give mount() a container. The pinned version makes the example reproducible.

The examples below assume an element with id="diagram".

<div id="diagram" class="pele-white"></div>
<script src="https://cdn.jsdelivr.net/npm/pele@1.12.0/dist/pele.global.js"></script>

Set the white theme

Set Pele’s documented variables on the container. They inherit into the generated SVG.

Use your own class name so these choices do not affect every diagram on the page.

.pele-white {
  --pele-bg: #ffffff;
  --pele-fg: #1a1a1a;
  --pele-muted: #52615a;
  --pele-line: #1a1a1a;
  --pele-surface: #ffffff;
  --pele-surface-alt: #edf3f0;
  --pele-border: #9aaca3;
  --pele-accent: #176b4e;
  --pele-radius: 8px;
}

Add drop shadows

Target Pele’s .pele-node class with SVG’s drop-shadow() filter.

--pele-drop-shadow is our custom variable. Declaring it alone would do nothing; the filter rule consumes it.

.pele-white {
  --pele-drop-shadow: 3px 4px 5px rgb(0 0 0 / 22%);
}

.pele-white .pele-node {
  filter: drop-shadow(var(--pele-drop-shadow));
}

Supply Lucide icons

Pass trusted Lucide SVG shapes through Pele’s existing icons callback. Pele supplies the icon frame.

The diagram labels below use names such as fa:fa-check. The callback maps those names to Lucide shapes; unknown names return nothing.

const lucideIcons = {
  check: '<path d="M20 6 9 17l-5-5"/>',
  x: '<path d="M18 6 6 18"/><path d="m6 6 12 12"/>',
  zap: '<path d="M4 14a1 1 0 0 1-.78-1.63l9.9-10.2a.5.5 0 0 1 .86.46l-1.92 6.02A1 1 0 0 0 13 10h7a1 1 0 0 1 .78 1.63l-9.9 10.2a.5.5 0 0 1-.86-.46l1.92-6.02A1 1 0 0 0 11 14z"/>'
};

pele.mount(document.querySelector('#diagram'), source, {
  icons: name => lucideIcons[name.replace(/^fa:fa-/, '')]
});

Animate with CSS

A small opacity entrance works without changing Pele’s SVG layout. Always disable non-essential motion for readers who request reduced motion.

Avoid animating CSS transform on positioned SVG groups unless you have checked that it does not override their placement.

@keyframes pele-fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

.pele-white .pele-node {
  animation: pele-fade-in 420ms ease-out both;
}

@media (prefers-reduced-motion: reduce) {
  .pele-white .pele-node {
    animation: none;
  }
}
