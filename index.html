Pele, styled without touching core.

Add a white theme, elevated shadows, intro-and-loop motion, and Lucide icons using Pele’s existing CSS hooks and icons option. No fork, plugin, build step, or modified Pele bundle.

Stock Pele 1.12.0 One HTML file CSS + vanilla JavaScript

Start with stock Pele

Load Pele’s browser build and give mount() a container. The pinned version makes the example reproducible.

The examples below assume an element with id="diagram".

<div id="diagram" class="pele-white pele-intro pele-loop"></div>
<script src="https://cdn.jsdelivr.net/npm/pele@1.12.0/dist/pele.global.js"></script>

Set a white theme

Set Pele’s documented variables on the container. They inherit into the generated SVG.

Use your own class name so these choices do not affect every diagram on the page.

.pele-white {
  --pele-bg: #ffffff;
  --pele-fg: #1d1c1a;
  --pele-line: #3f3c37;
  --pele-surface: #fefdfa;
  --pele-surface-alt: #f8f6f0;
  --pele-border: #ddd8cc;
  --pele-accent: #2f63ad;
  --pele-radius: 8px;
}

Add elevated shadows

Stack three shadows (contact, short, long) in an SVG <filter> inside one hidden <svg> on the page, then point Pele’s classes at it. Cards lift higher on hover; clusters and edge labels get lighter filters of their own.

Why not CSS drop-shadow()? Safari does not draw it on shapes inside an SVG. filter: url(#…) works in every browser. Hide that <svg> with zero size, not display: none, which turns its filters off.

<filter id="pele-lift" x="-60%" y="-60%"
        width="220%" height="280%">
  <!-- per layer: blur, offset, tint -->
  <feGaussianBlur in="SourceAlpha" stdDeviation="4"/>
  <feOffset dy="6" result="o1"/>
  <feFlood flood-color="#1d1c1a" flood-opacity=".22"/>
  <feComposite in2="o1" operator="in" result="s1"/>
  …
  <feMerge>… <feMergeNode in="SourceGraphic"/></feMerge>
</filter>

.pele-white :is(.pele-node, .pele-task, .pele-slice) {
  filter: url(#pele-lift);
}
.pele-white .pele-node:hover { filter: url(#pele-lift-hover); }
.pele-white .pele-cluster > rect { filter: url(#pele-sheet); }

Supply Lucide icons

Pass trusted Lucide SVG shapes through Pele’s existing icons callback. Pele supplies the icon frame.

The diagram labels below use names such as fa:fa-check. The callback maps those names to Lucide shapes; unknown names return nothing.

const lucideIcons = {
  check: '<path d="M20 6 9 17l-5-5"/>',
  x: '<path d="M18 6 6 18"/><path d="m6 6 12 12"/>',
  zap: '<path d="M4 14a1 1 0 0 1-.78-1.63l9.9-10.2a.5.5 0 0 1 .86.46l-1.92 6.02A1 1 0 0 0 13 10h7a1 1 0 0 1 .78 1.63l-9.9 10.2a.5.5 0 0 1-.86-.46l1.92-6.02A1 1 0 0 0 11 14z"/>'
};

pele.mount(document.querySelector('#diagram'), source, {
  icons: name => lucideIcons[name.replace(/^fa:fa-/, '')]
});

Animate: intro, then loop

The intro builds the drawing: cards rise one after another, lines are wiped in along the flow, and labels pop in. The loop then turns every line into moving dashes. Classes on the container choose either or both.

The stagger is plain CSS: :nth-child() gives each card and line an index --i, and the delay is computed from it.

Move cards with the CSS translate property, which adds to Pele’s transform attribute rather than replacing it. Cards cast no shadow while moving, which keeps the animation smooth. All motion sits inside prefers-reduced-motion: no-preference.

.pele-nodes > :nth-child(2) { --i: 1; }  /* … up to 12 */

@media (prefers-reduced-motion: no-preference) {
  .pele-intro .pele-node {
    animation: pele-rise 520ms backwards;
    animation-delay: calc(150ms + var(--i) * 110ms);
  }
  .pele-intro .pele-edge {
    animation: pele-wipe 650ms backwards;
    animation-delay: calc(350ms + var(--i) * 110ms);
  }
  .pele-loop .pele-edge > path:not(.pele-marker) {
    stroke-dasharray: 5 4;
    animation: pele-flow 1s linear infinite var(--loop-delay);
  }
}

@keyframes pele-rise {
  from { opacity: 0; translate: 0 10px; filter: none; }
  to { filter: none; }
}
@keyframes pele-wipe {
  from { clip-path: inset(0 100% 100% 0); }
  to { clip-path: inset(-20px); }
}
@keyframes pele-flow { to { stroke-dashoffset: -18; } }
